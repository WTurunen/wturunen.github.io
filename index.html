Talteen

Restore deleted issues and attachments in Jira Cloud

Jira Cloud deletes issues (work items) and attachments for good. Talteen keeps a copy on your own Jira site. A site admin can restore a deleted issue with its fields, comments, links and files, or put a deleted file back on the issue it came from.

It can only restore what was deleted after you installed it, so install it before you need it.

Deleted issues are kept
60 days. You can set 1 to 365.
Deleted files are kept
14 days. You can set 1 to 90.
Where the copies are
Forge storage on your own Jira site. Nothing is sent to an outside service.
Who can restore
Site admins. Project admins too, if you allow it.
What does not come back
The original key, status, created date and change history. Known limitations has the full list.
